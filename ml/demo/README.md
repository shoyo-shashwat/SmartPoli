# Twin tab design prototypes

Static HTML prototypes used to design the Digital Twin tab (open them through a local web server, for example `python -m http.server` from the repo root).
They replay sugar readings, meals and insulin from one anonymised recording of the **ShanghaiT2DM** dataset (Zhao et al., *Scientific Data* 2023, CC BY 4.0).
That is real research data, not a made-up patient. The forecast numbers inside these prototypes are illustrative; the working feature is the Twin tab in `backend/`.
