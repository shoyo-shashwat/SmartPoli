# Digital Twin demo patient data

`demo_a.json`: one recording (2094_0_20211109) from the **ShanghaiT2DM** dataset, an anonymised, openly published
research dataset: Zhao Q. et al., "Chinese diabetes datasets for data-driven machine learning", *Scientific Data* 2023,
licensed **CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/). It holds continuous-glucose readings put on a
15-minute grid, logged meals and insulin doses, and the patient's anonymised background facts. The patient is shown as
"Demo patient A". This is real research data, not a made-up patient, and it must always be credited. The Twin tab shows the credit.

Only the Twin demo copy uses it; the live SmartPoli app never loads it.

`demo_b.json` (CGMacros) is NOT stored in this repo: that dataset has a share-alike, non-commercial licence.
